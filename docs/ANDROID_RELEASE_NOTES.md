An Android testing build of FocusBubble, built and signed by Expo EAS.

## Download and install

1. Download the `.apk` attachment below on your Android phone.
2. Allow your browser or file manager to install this app when Android asks.
3. Open FocusBubble. This standalone preview includes the native bubble and does not need Expo Go or Metro.

## Try the full Android feature set

- Create a goal with motivation, a date and roadmap steps.
- Start a short focus session, pause/resume, lock the phone and return.
- Open the floating-bubble screen, grant “Display over other apps”, then enable the bubble.
- Switch to another app. Drag the bubble, tap for controls and pause/resume.
- Finish a session from the app or native controls and check the saved history.
- Optionally enable notifications separately in Settings.
- Restart the app and confirm goals, steps, preferences and session restoration.
- Try backup export/import before relying on it for important goals.

This is a prerelease for device testing. Android and phone-manufacturer policies may restrict overlays or background execution. No overlay is guaranteed on secure system screens. Report your Android version, phone model and reproduction steps with any issue.

`SHA256SUMS.txt` contains the APK checksum. Keep existing app data by installing updates signed with the same Expo-managed Android keystore; export a backup before uninstalling.
